
# PRD：跨境电商 AI 商品导购 Agent

## 1. 产品目标

面向海外 Temu/Amazon 用户，搭建 AI 导购 Agent，基于商品知识库做商品推荐、参数问答；严格抑制大模型幻觉，可量化评测模型效果，沉淀 bad case 持续迭代。

## 2. 用户角色

美国跨境电商消费者，英文提问，需要根据预算、用途、属性筛选商品。

## 3. 核心功能

1. 商品知识库管理：原始商品数据清洗、结构化、标签生成、数据质量校验
2. 多轮导购对话：用户英文 query 理解，召回知识库商品，生成合规回答
3. 模型评测能力：批量测试 query，多模型横向对比，自动归类 bad case
4. 幻觉管控：强制约束大模型只能使用知识库内商品信息，禁止编造参数

## 4. 非功能需求

1. 回答必须基于知识库，禁止编造不存在商品 / 参数
2. 输出格式统一，便于自动评测
3. 所有 bad case 可记录、可统计、可归因

## 5. 业务指标

- 商品参数准确率（降低幻觉）
- 推荐相关性
- Bad case 占比持续下降

## 6. 迭代规划

V1：完成知识库、Prompt 约束、评测框架（当前版本）
V2：优化 RAG 召回策略，提升推荐相关性
V3：增加自动 bad case 根因分析，支持批量模型调优
